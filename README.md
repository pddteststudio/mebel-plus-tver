# «Мебель Плюс» — Тверь

Независимая демонстрационная концепция сайта для мебельной мастерской из Твери. Не является официальным сайтом компании.

## Как посмотреть

Откройте `index.html` после распаковки архива. Остальные страницы: `projects.html`, `kitchens.html`, `storage.html`, `materials.html`, `planner.html`, `contacts.html`.

Автономные `preview-*-offline.html` — версии страниц со встроенными стилями, иллюстрациями и JS, удобные для показа без сервера. Они предназначены для просмотра каждой страницы по отдельности; для переходов используйте основной сайт.

## Публикация на Vercel

1. Загрузите **содержимое** папки проекта в GitHub (чтобы `index.html` оказался в корне репозитория).
2. Vercel → Add New → Project → Import Repository.
3. Framework Preset: **Other**, Build Command не задавайте, Output Directory оставьте `.`.
4. Нажмите Deploy.
5. До официального запуска согласуйте с мастерской коммерческие условия и разрешение использовать фото, уберите ограничения индексации при необходимости.

Проект статический (HTML, CSS, JavaScript, SVG), сборка, база данных и установка зависимостей не требуются.

## Функции

- Семь адаптивных страниц.
- Шесть историй с фильтрами, модальными карточками и описаниями.
- Выбор условных вариантов отделки на странице материалов.
- Визуальный подбор мебели: вид изделия, планировка, размеры, МДФ/ЛДСП, рельеф и цвет, опции и пожелания.
- Фото JPG/PNG/WebP (до 3 файлов по 7 МБ) с локальным предпросмотром и удалением.
- Проверка размеров, готовый текст заявки, копирование в буфер и переход в сообщения VK.
- Мобильная навигация, блок FAQ и контакты.

**Важно:** фото остаются на устройстве пользователя и не отправляются в VK автоматически. Покупатель самостоятельно вставляет скопированный запрос и прикрепляет фотографии к сообщению.

Все девять SVG-сцен разработаны для демонстрации. Они **не являются фотографиями реальных заказов**. Ноябрьские описания кухонь взяты из публичных публикаций VK, но их производственное происхождение требует подтверждения. Две истории хранения — концептуальные.

**Не придуманы:** телефон, адрес, прайс, сроки изготовления, отзывы или количество выполненных заказов. Сообщество заявляет бесплатный 3D-проект и замер, скидку и гарантию, но актуальные условия нужно согласовать непосредственно с компанией. Без достоверного прайса денежный калькулятор не включён.
